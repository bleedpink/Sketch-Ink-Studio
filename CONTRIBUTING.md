# Contributing to Sketch & Ink Studio

Thanks for helping improve Sketch & Ink Studio. This project is source-available for noncommercial use under the PolyForm Noncommercial License 1.0.0; it is not an OSI-approved open-source project because commercial use is restricted.

## Before starting
- Search existing issues before opening a duplicate.
- For substantial changes, open an issue first to discuss the approach.
- Never include private files, credentials, or personal data in issues.
- Only submit code, designs, documentation, and assets you have the right to contribute under the project's noncommercial license terms.

## Pull requests
- Keep each PR focused on one bug or feature.
- Describe the problem, solution, trade-offs, and any user-facing changes.
- Include reproduction steps for bug fixes and screenshots or recordings for UI changes.
- Test in at least one desktop browser and, when relevant, one touch device. State exactly what you tested.
- Preserve project-file compatibility where possible and call out format changes.
- Do not add dependencies, analytics, tracking, or network calls without explaining why.

## Reporting bugs
Include browser/device, steps to reproduce, expected behavior, actual behavior, and console errors where possible.
