## 🌷 About the project

<img width="1280" height="1280" alt="1000340208" src="https://github.com/user-attachments/assets/05f8eb5b-5de9-442d-93b1-ef1baba98532" />

**Sketch & Ink Studio** is a lightweight, browser-based creative workspace for people who want to draw, sketch, and explore animation without starting with a complicated setup.

The goal is simple: make creative tools feel approachable. Open the site, make a little space for your imagination, and see where it takes you. Whether you're practising your lines, testing a character idea, or just doodling for fun, this project is made for creative curiosity.

The project is shared publicly so people can explore how it works, suggest improvements, report bugs, and contribute under its noncommercial license.

## ✨ Features

- 🎨 **Browser-based creative workspace** — use the app through a web browser.
- ✏️ **Drawing and sketching** — a place to explore visual ideas and make artwork.
- 🎞️ **Animation-focused creativity** — experiment with bringing ideas to life.
- 📱 **Progressive Web App (PWA) support** — includes PWA files for compatible installation experiences.
- 🧩 **Standalone HTML version** — a single-file version is provided for a simple way to try the app.
- 🪶 **Lightweight project structure** — built around web technologies, with no traditional desktop installer required.
- 💌 **Community-friendly development** — bug reports, thoughtful feedback, and contributions are welcome.

> Feature availability can vary by browser and version. If something doesn't work as expected, please open an issue with your browser/device details and steps to reproduce it.

## 💻 Run locally

You can run the project locally using a simple static web server.

### Option A — Python

If Python is installed, open a terminal in the folder containing `index.html` and run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

### Option B — Visual Studio Code

1. Open the project folder in Visual Studio Code.
2. Use a local web-server extension if you already have one installed.
3. Open the local address provided by that server.

Keep the folder structure intact: the HTML file may rely on adjacent scripts, icons, styles, or PWA files.

## 🌐 Publish with GitHub Pages

You can host the static site on GitHub Pages without purchasing a custom domain.

1. Upload the **contents** of the release folder to the repository—not just the ZIP archive.
2. Make sure `index.html` is in the repository root, unless your Pages configuration points to another folder.
3. Open **Settings → Pages** in your GitHub repository.
4. Under the build/deployment options, choose deployment from the `main` branch and the root folder (`/`) if that matches your repository layout.
5. Save and wait for GitHub Pages to publish the site.
6. Add the resulting public URL to the **Try the hosted version** section above.

GitHub may take a few minutes to publish a new or updated site. Check the Pages status if the URL does not work immediately.
